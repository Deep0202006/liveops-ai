# Frontend: Do Not Duplicate

The frontend must not calculate RUL targets, engineer features, scale or impute data, remove constant features, split machines, load artifacts, choose models, calculate metrics, derive maintenance status, create prediction ranges, or invent explanations/model metadata.

Render backend-returned values and warnings. Do not turn demo metrics into headline accuracy, hide `demo_only`, reinterpret cycles as hours, or silently switch from real to demo mode.
