# Public frontend contract

The frontend consumes HTTP API v1 only. It retains the browser `File` and resends it to stateless multipart dataset inspection, machine inspection/series, and prediction endpoints. It must never implement RUL targets, feature engineering, preprocessing, thresholds, prediction ranges, explanations, artifact loading, or metrics. API v1 is final; use `docs/web-api/openapi-v1.json`.
