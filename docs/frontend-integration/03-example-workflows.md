# Example Workflows

For frontend development:

1. Run `python scripts/build_demo_artifact.py`.
2. Instantiate an explicitly demo-configured `RULService`.
3. Call `get_status()` and display the demo warning.
4. Load one `data/sample/demo_machine_*.csv` file.
5. Call validation, machine listing/summary, then `predict`.
6. Render the returned unit, status, range, warnings, important features, and recent changes.

The JSON files in `examples/` were generated by `python scripts/generate_frontend_examples.py` from actual service calls. They cover unavailable, demo, prediction, validation, insufficient-history, corruption, evaluation, and metadata results.
