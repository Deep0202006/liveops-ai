# Information architecture

The approved route set is `/`, `/app`, and `/app/model`.

- `/`: product explanation, honest model evidence, four-step process, real demo workflow preview, trust/limitations, and minimal footer.
- `/app`: deterministic upload-to-prediction workspace. On mobile, the RUL result precedes secondary charts.
- `/app/model`: real API-backed model identity, official evaluation, baseline comparison, near-failure performance, target/feature method, provenance, limitations, and versions.

Global navigation contains only Product, Model evidence, and Open workspace. Status is exposed through a keyboard-accessible drawer rather than a fourth route. Authentication, settings, history, alerts, notifications, and persistence are intentionally absent.
