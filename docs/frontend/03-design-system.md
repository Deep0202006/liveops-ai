# Signal Foundry design system

Signal Foundry uses a single CSS token source with the locked near-black surfaces, off-white text, mint signal, blue information, amber warning, red critical, and green healthy values. Purple is excluded. Geist Sans serves interface text; Geist Mono and tabular numbers serve identifiers, cycles, versions, and metrics.

The layout targets 1440 px, remains meaningful through 1560 px, and supports 1024 px desktop and 390 px mobile. Product cards use 20–24 px padding and 24–32 px section gaps. The desktop rail is 72 px collapsed and no more than 220 px expanded; mobile uses a focus-trapped sheet.

The signature is a horizontal RULHorizon with observed history, predicted remaining cycles, backend bounds, and maintenance thresholds. It is not a gauge and never invents a failure timestamp. SensorLattice is limited to the hero and empty workspace. FocusLensCard is limited to upload, primary RUL, and evidence summary.
