# Command-center storyboard

At 1440 × 900 the eye path is: live/scenario state in the compact glass bar → open KPI ribbon → selected asset RUL → fleet context → alerts and maintenance → floating Time Conductor.

The glass command bar contains identity, scenario from the loaded catalog, live-simulation qualification, `T+cycle`, play/pause, scenario, allowed speed, API/model state, command palette, and fullscreen. The rail exposes Command Center, Fleet, Maintenance, Compare, Model Evidence, and Data Lab.

The KPI ribbon is one surface with Assets online, Critical assets, Maintenance due, Under watch, Median RUL, and Active alerts. Only changed values receive the 180 ms arrival treatment.

Fleet Health remains a searchable/status-filtered/sortable matrix. Each tile shows asset ID, explicit status, predicted RUL, delta, source cycle, sparkline, alert count, freshness, and pin state. Selection outlines once; only a selected critical asset may beacon.

Selected Asset Command View carries identity and model-backed status first, a dominant linear RUL Horizon second, then telemetry and evidence. The horizon shares one scale for range, critical/warning thresholds, current value, and forecast wording. Missing bounds show an explicit unavailable range; zero and four-digit values remain within the same layout.

Alert and Maintenance Intelligence uses compact rows and explicit severity/status text. Existing severity, asset, and event-type filters remain immediate. The queue shows rank, asset, RUL, decline, status, inspection guidance, reason, and review state.

Time Conductor floats as command glass and preserves play, pause, step, reset, speed, seek, current/end cycle, time window, next warning, next critical, commands, and help. Event markers are derived from the scenario event contract.

Comparison remains `/compare`, uses one elevated operational surface, shared RUL and cycle axes, one sensor selector, textual summaries, and deterministic recommended review order. Asset colours remain stable between overview, trend, sensor plot, and legend.
