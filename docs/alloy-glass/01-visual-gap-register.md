## Anchor-surface implications

Surface A must be created because no current landing experience exists. Surface B should first resolve VG-02 through VG-10 and VG-16; otherwise subsequent component polishing will reinforce the existing hierarchy. The anchor gate should be judged from a deterministic 1440×900 command-center state plus desktop/tablet/mobile landing captures, not from isolated component screenshots.
