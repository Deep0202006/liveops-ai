# Information architecture

- Compact command bar: identity, FD001 fleet, simulation disclosure, virtual cycle, scenario and playback controls, system status, fullscreen.
- Navigation rail: Command Center, Fleet, Maintenance, Model Evidence, Data Lab.
- Command Center: KPI strip; fleet matrix; selected-asset RUL and telemetry; alert feed; maintenance queue; persistent Time Conductor.
- Asset route: focused telemetry, RUL trend, evidence, and warnings.
- Maintenance: ranked deterministic priorities and comparison.
- Model: existing evidence experience adapted to the operational shell.
- Data Lab: existing upload, validation, inspection, and prediction workflow.
