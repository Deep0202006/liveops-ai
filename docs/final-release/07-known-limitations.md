# Known limitations

- FD001 is simulated turbofan benchmark data with one operating condition and degradation mode; it is not factory certification.
- Maintenance thresholds are demonstration thresholds.
- Validation-residual ranges are estimates, not guarantees.
- The API has no authentication and should use same-origin/local trusted access for this academic scope.
- Vercel build awaits valid account authentication; deployment has not occurred.
- The professional visual frontend remains to be implemented.
